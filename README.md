# Valentina Lorca

Personal landing page — [valentinalorcap.com](https://valentinalorcap.com)

Built with [Next.js](https://nextjs.org) (App Router), React 19, and Tailwind CSS.

## Development

Requires Node 22 (see `.nvmrc`).

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command             | Description                |
| ------------------- | -------------------------- |
| `npm run dev`       | Start the dev server       |
| `npm run build`     | Production build           |
| `npm run start`     | Serve the production build |
| `npm run lint`      | Run ESLint                 |
| `npm run typecheck` | Run TypeScript checks      |
| `npm run format`    | Format with Prettier       |

## Deployment

Deployed on [Vercel](https://vercel.com), connected to this repository — every push to `main` redeploys automatically.
